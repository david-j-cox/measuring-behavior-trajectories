| Dynamical Systems Term          | Definition                                                                                                                                                                                                | Behavior-Analytic Equivalent/Analog                                                                                                         | Analysis Method(s)                                     |
|:--------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------|
| Attractor                       | A state or set of states toward which a system tends to evolve over time, regardless of starting conditions.                                                                                              | Steady-state preference / equilibrium response allocation                                                                                   | Phase-space reconstruction; RQA                        |
| Trajectory                      | The path traced by a system through its state space as it evolves over time.                                                                                                                              | Behavioral time series / response path over time                                                                                            | Time-series construction; all pipeline steps           |
| Phase space / State space       | A multi-dimensional space in which each axis represents one variable of the system, so that every possible state corresponds to a unique point.                                                           | Multi-dimensional representation of behavior (e.g., choice proportion × reward rate plotted together)                                       | Delay embedding; phase-space reconstruction            |
| Bifurcation                     | A qualitative change in the system's dynamics (e.g., number or stability of attractors) caused by a smooth change in a control parameter.                                                                 | Regime shift / abrupt change in contingency–behavior relationship                                                                           | Phase-transition analysis                              |
| Recurrence                      | The property of a trajectory returning to a neighborhood of a previously visited state in phase space.                                                                                                    | Pattern revisitation / returning to a previously observed behavioral state                                                                  | Recurrence Quantification Analysis (RQA)               |
| Determinism (RQA)               | The proportion of recurrent points that fall on diagonal lines in a recurrence plot, indicating predictable sequential structure.                                                                         | Sequential predictability / the degree to which behavioral sequences form repeating patterns                                                | Recurrence Quantification Analysis (RQA)               |
| Hurst exponent / DFA α          | A scaling exponent that quantifies the degree of long-range temporal correlations in a time series. Values above 0.5 indicate persistent (positively correlated) fluctuations.                            | Long-range dependence / behavioral persistence or memory across time scales                                                                 | Detrended Fluctuation Analysis (DFA); fractal analysis |
| Sample entropy                  | A measure of the complexity or irregularity of a time series, defined as the negative natural logarithm of the conditional probability that similar patterns remain similar at the next point.            | Behavioral complexity/regularity / unpredictability of the choice sequence                                                                  | Entropy estimation; fractal analysis                   |
| Embedding dimension             | The number of time-delayed copies of a scalar time series needed to unfold the system's dynamics in a reconstructed phase space (per Takens' theorem).                                                    | Effective degrees of freedom / the minimum number of lagged variables needed to reconstruct the system's dynamics                           | Delay embedding; simplex projection                    |
| Convergent cross-mapping (CCM)  | A method for detecting causal relationships between time series by testing whether the state-space reconstruction of one variable can predict the other, with prediction improving as more data are used. | Causal coupling / testing whether one variable (e.g., reward) causally drives another (e.g., choice) beyond correlation                     | Convergent cross-mapping (CCM)                         |
| S-Map (state-dependent mapping) | A locally weighted forecasting method that allows the relationship between variables to change depending on the current location in state space.                                                          | Context-sensitive dynamics / whether the rules governing behavior change depending on the current behavioral state                          | S-Map analysis                                         |
| Simplex projection              | A nearest-neighbor forecasting method that predicts future values by finding similar past states in a delay-embedded phase space and averaging their successors.                                          | Nonlinear forecasting / predicting future behavior from past trajectories using nearest-neighbor methods                                    | Simplex projection; embedding dimension estimation     |
| Hysteresis                      | The dependence of a system's state on its history, so that the path followed when a parameter increases differs from the path when it decreases.                                                          | Path dependence / behavior depending not just on current contingencies but on the history of contingency changes                            | Phase-transition analysis; transition metrics          |
| Laminarity (RQA)                | The proportion of recurrent points that form vertical lines in a recurrence plot, reflecting epochs where the system remains in roughly the same state.                                                   | Behavioral trapping / tendency to persist in the same state for extended periods                                                            | Recurrence Quantification Analysis (RQA)               |
| Hidden Markov Model (HMM)       | A probabilistic model positing a sequence of unobserved (hidden) states, each generating observations according to state-specific emission distributions, with transitions governed by a Markov chain.    | Latent behavioral states / unobserved internal states that generate observable choice patterns (cf. “response states” in behavior analysis) | Hidden Markov Model fitting; state classification      |
| Matching law                    | The empirical generalization that the relative rate of responding on an alternative matches the relative rate of reinforcement obtained from that alternative.                                            | Molar contingency tracking / proportional allocation of behavior to relative reinforcement rates                                            | Matching-law regression; RL model comparison           |
